### 🔥 About the Game

**Pokémon: Quest of Legend** is a top-down pixel RPG where players explore a vibrant overworld, enter battle areas, and trigger move-based combat using simple controls.

> ⚠ This is a **non-commercial fan project**. All Pokémon assets and trademarks belong to their respective owners.

---

### 🕹 Controls

| Action | Key / Input |
|--------|-------------|
| Move Forward | **W** |
| Move Backward | **S** |
| Move Left | **A** |
| Move Right | **D** |
| Use Move in Battle | **Mouse Click** |
| Toggle Tutorial | **P** |
